Get started

Three steps to play together

  1. 1Download the companion. It installs the Sagalore addon into your WoW folder.
  2. 2Keep it running and log in with Battle.net when prompted. Leave it in the menu bar / tray.
  3. 3In game, type /reload. Open the log — invite friends, share a saga, and compete.

Open source

Free, open, and honest about hosting

Sagalore is free and open source. The addon, companion, and API are on GitHub — anyone can run their own server.

  • The project MIT-licensed on GitHub. Read the code, fork it, self-host with your own Battle.net app.
  • The official server The easiest start is sagalore.app — free to use. Your data lives there; you sign in with Battle.net.
  • The MCP The official MCP lets your AI create sagas. It is built on the open Sagalore API and runs on Smia, a platform we also make. It is not in the repo so Sagalore stays independent of any one platform — and so we can show people Smia. Want your own MCP? The API is documented. Build away.
