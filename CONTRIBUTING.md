# Contributing

Sagalore is MIT licensed. Anyone may run it and anyone may fork it.

Pull requests on this repository stay limited to collaborators. If you are not a collaborator, use your fork.

Do not commit secrets: `.env`, tokens, or Battle.net client secrets. The Go module path stays `github.com/sagalore/sagalore`.

Before you send a change, run `go test ./...` and the Lua tests listed in the Makefile.
